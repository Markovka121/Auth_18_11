# Назначение
 Предназначен для авторизации пользователей с логином и паролем




# Как открыть:
1. Открываете консоль "Win + R"
2. Переходите в папку где лежит файл cd <путь>
3. и открывете с помощью комманды:
```
Python AUTH.PY
```
